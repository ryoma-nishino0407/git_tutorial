Gitチュートリアル

git status

git diff

git diff --staged

git checkout -- index.html

status -> st, commit -> ci, checkout -> co, branch -> br

git reset HEAD index.html

git commit --amend #直前のコミットをやり直す

git remote -v #リモートの情報を確認(-vでURLも)

git fetch origin #リモートからローカルに取得する

git merge origin/master #ローカルからワークツリーに統合

git pull origin master #fetchとmergeを同時に
